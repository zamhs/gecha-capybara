# Para Gecha ♡ — Capy Care Club

Una landing page estática, responsive, sin frameworks, dedicada a Gecha. Un mini manual de cuidados para resfriado/gripe con ilustraciones capibara, checklist persistente y un botón de abrazos.

## Desarrollo

Abre `index.html` o usa `python3 -m http.server 8080` desde esta carpeta y visita http://localhost:8080.

## Publicación

Compatible con GitHub Pages, incluyendo la publicación desde la raíz de la rama `main`.

## Cuidado médico

La página explica medidas generales de autocuidado, señales de alarma y cuándo consultar. No sustituye consejo ni diagnóstico médico. Fuentes CDC: https://www.cdc.gov/common-cold/es/treatment/manejo-del-resfriado-comun.html y https://www.cdc.gov/flu/es/takingcare/influenza-que-hacer-si-se-enferma.html.
